# Africa Germany Pathways

Build a complete, modern and professional job portal called AzubiAfrica, focused on helping people across Africa find vocational training opportunities (Ausbildung) in Germany.

1. Main Goal:
Create a real, functional website where African applicants can discover Ausbildung opportunities in Germany and apply directly through the employer's official website.

2. Design:
- Modern, professional and trustworthy design.
- Use navy blue, white and subtle green accents.
- Fully responsive on mobile, tablet and desktop.
- Clean layout inspired by professional German job portals.
- Use professional typography, cards, icons and subtle animations.
- Make the website fast, accessible and easy to navigate.

3. Languages:
- German as default language, with French and English options.
- Language switcher in the navigation bar.
- Translate the main navigation, filters, buttons and informational pages.

4. Homepage:
- Hero section: "Finde deine Ausbildung in Deutschland" with a subtitle explaining that the portal helps applicants across Africa discover German vocational training opportunities.
- Search bar for job title, occupation or company.
- Filters for German city, profession, training start date, and German language level.
- Featured Ausbildung opportunities.
- Popular categories.
- Recently added opportunities.
- A section explaining how to apply from Africa.
- Clear CTA to explore all available opportunities.

5. Job Categories:
- Pflege und Gesundheit
- IT und Fachinformatik
- Handwerk
- Technik und Mechatronik
- Logistik
- Gastronomie und Hotellerie
- Kaufmännische Berufe
- Elektronik
- Produktion

6. Job Listings:
Every job card displays:
- Job title and Ausbildung profession
- Employer name
- German city and postal code
- Training start date
- Ausbildungsvergütung (salary/stipend)
- German language level
- Application deadline
- Date when listing was last verified
- "Details ansehen" button
Sorting and filters for city, profession, start date, language requirements, and application deadline.

7. Job Details Page:
Every job must include:
- Employer name and location
- Ausbildung title and description
- Requirements and qualifications
- German language level
- Training start date and application deadline
- Salary (Ausbildungsvergütung), when available
- Whether international applicants can apply, only when verified
- Original source URL and last verification date
- A prominent "Jetzt beim Unternehmen bewerben" button linking to the employer's official application page

8. Additional Features & Rules:
- Admin dashboard for managing listings.
- Preparation for future imports from authorized APIs or RSS feeds.
- Use clearly labelled demo listings only. Do not invent real job offers or claim that visa support is available unless verified.
- Prioritize a functional MVP with no paid third-party dependencies required.
